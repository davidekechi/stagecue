**Status: PENDING — needs access to the project's Laravel Cloud organisation.**

Until this spike is run, the app keeps `STAGECUE_HEARTBEAT_MODE=whisper` (decision D6, the default).
The HTTP fallback (T5.11, LLD §6.4) is built behind the same config flag so the switch is a config change only.

## How to run it
1. Follow 06-Deployment §2–4: create the `staging` environment on the `develop` branch, attach Serverless Postgres and a WebSocket cluster.
2. Deploy, then open two browsers on the staging host, pair them, and watch the heartbeat
   indicator in the Display's SetupPanel (the real heartbeat code replaces the throwaway `/spike` page).
3. Record the results below and set `STAGECUE_HEARTBEAT_MODE` on the environment.
